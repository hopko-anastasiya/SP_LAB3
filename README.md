# Лабораторна робота 3
## Виконано: Гопко Анастасія, ТТП-32

1. Розбирає програму (лексер на Flex, LALR(1)-парсер на Bison) і будує AST.
2. Виконує програму, обходячи AST (інтерпретатор).
3. Генерує код на JavaScript (`out.js`).
4. Візуалізує AST у браузері засобами d3.js (`ast_visualizer.html`).

## Підтримувані конструкції

- оголошення: `int x;`, `int x = 5;`
- присвоєння: `x = x + 1;`
- арифметика: `+ - * /`, унарний мінус, дужки
- порівняння: `< > <= >= == !=`
- `if` / `else`, `while`, блоки `{ ... }`
- вивід: `printf("%d\n", x);` або `print(x);`
- коментарі `//` і `/* ... */`

## Файли

| Файл | Призначення |
|---|---|
| `lexer.l` | лексичний аналізатор (Flex) |
| `parser.y` | граматика і `main` (Bison) |
| `ast.h` | вузли AST, інтерпретатор, генерація JS, візуалізація |
| `test.c` | тестова програма |

## Збірка і запуск

Потрібні: `flex`, `bison`, `gcc`, `nodejs`.

```bash
sudo apt install flex bison gcc nodejs
make            # зібрати
./lab test.c    # аналіз, обчислення, генерація out.js і ast_visualizer.html
node out.js     # запустити згенерований JavaScript
make clean      # видалити згенеровані файли
```

Візуалізацію відкрийте у браузері: `firefox ast_visualizer.html` (потрібен інтернет для завантаження d3.js).
